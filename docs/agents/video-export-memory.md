# 篮球高光导出约定

- 高光范围：按 V3 工程的命中投篮与防守高光，事件前 5 秒、后 3 秒，按工程中的排除项和手动片段边界处理。
- 输出：每个工程生成 `sy`、`dragon`、全场三份高光视频及对应 UTF-8 SRT，目录名固定为 `highlight clips`。
- 裁切：使用精确转码模式（慢速、帧级裁切），不使用 `-c copy` 快剪；字幕时间线必须以转码后拼接视频为准。
- 单人字幕：两行，第一行为“`sy 2 分·`”格式，第二行为“`1 / 4 25.0%`”格式；事件点显示 0.1 秒，不显示“命中/防守”等事件文字。
- 全场字幕：事件点显示完整比分，格式为“`sy 52 - 48 dragon`”，显示 0.1 秒。
- 待办：命中率字幕改为累计统计；后续脚本需把此前投篮数量一并纳入累计分母，再重新生成字幕。
