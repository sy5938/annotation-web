# 篮球视频标定台

本地优先的篮球视频手动标定工具。视频直接在浏览器中读取，不上传；标定工程保存为可继续编辑的 JSON 文件。

当前正式版本：**V0.2**（Git 标签 `v0.2.0`），包含可修剪的个人高光预览。

## 功能

- 记录进 2 分、进 3 分、未进和好防守
- 分别设置甲、乙的初始比分，并在当前视频得分上续算总比分
- 为每次投篮记录结果；球位置关键帧作为可选标注，默认收起
- 在人工复核时间轴中拖动定位，直接拖动投篮点或关键帧修改时间
- 时间轴位于视频控制栏下方，进球、未进、好防守和待确认标记可通过图例分别显示或隐藏
- 按全场、甲或乙生成进球和 Good defense 高光，每条事件可独立纳入或排除
- 高光默认保留事件前 5 秒、后 3 秒；重叠片段自动合并，并可人工修剪边界
- 显示球员命中数/总投篮数、命中率、Good defense 次数、预计片段和时长
- 按照片段清单连续预览，也可点击任意片段开始播放
- 选中关键帧后逐帧微调、更新时间、重画或删除；画面标记只在关键帧时刻出现
- 随时隐藏或显示篮筐、球框等画面标记
- 调整播放倍速和工程 FPS
- 导入新版工程，或自动迁移旧版平铺标注 JSON
- 打开包含多个工程和视频的工作文件夹，选择工程后自动匹配对应视频
- 撤销或重做投篮记录的新增与删除
- 导出带 `schema_version` 的新版标定工程

## 本地启动

需要 Node.js `>=22.13.0`：

```bash
npm install
npm run dev
```

打开终端显示的本地地址。日常使用不需要登录，也不需要网络服务。

## 工作流程

1. 点击“选择本地工作文件夹”选择素材目录；浏览器会显示原生的文件/目录选择窗口，但文件不会上传。单工程会直接打开，多工程会先让你选择工程。也可以继续单独打开视频或工程。
2. 播放到投篮结果，记录球员与结果。
3. 在视频上方的时间轴空白处按住拖动可定位视频；直接拖动事件标签可修改记录时间。
4. 点击图例中的“进球、未进、好防守、待确认”，可独立隐藏或显示对应事件。
5. 通过绿色/灰色热力条预览预计保留范围，并查看预览时长和片段数量。
6. 画面标记可以用一个总开关统一隐藏或显示，隐藏不会删除数据。
7. 需要标球位置时再展开“球位置关键帧（可选）”；可直接拖动彩色关键帧改时间，也可选中后前后微调一帧或重画。
8. 在左侧从“全部事件”切换到“高光”，再选择全场、甲或乙；事件列表会只显示当前高光子集。
9. 顶部整体时间轴显示完整视频中的全部高光区间和事件点；点击区间后，直接拖动该时间轴上的左右手柄修剪当前片段。
10. 点击“连续预览”播放全部高光；普通手动跳转会退出高光预览。
11. 点击“导出工程”保存 schema v3 JSON。高光方案只在主动导出时保存，不会自动覆盖原文件。

V3 导出始终保存完整工程，包括甲乙初始比分、最终比分摘要 `final_scores`、所有事件、所有球位置关键帧，以及全场/A/B 三套高光方案；当前页面处于“全部事件”或某个高光范围，不会过滤工程 JSON。

浏览器不会在只选择一个 JSON 后自行读取旁边的本机文件；“选择本地工作文件夹”通过一次目录授权，在该目录及子目录中匹配工程记录的视频文件名。

高光功能当前只提供预览和方案保存，不裁剪或生成视频文件。

## 快捷键

- `空格`：播放或暂停；即使操作按钮刚刚获得焦点，也不会重复执行该按钮
- `←` / `→`：后退或前进 5 秒
- 顶部 `−5 帧` / `−1 帧` / `+1 帧` / `+5 帧`：精确逐帧调整
- `[` / `]`：切换关键帧
- `-` / `+`：调整播放倍速
- `Z` / `X` / `C` / `V`：球员甲记录 2 分、3 分、好防守、未进
- `A` / `S` / `D` / `F`：球员乙记录 2 分、3 分、好防守、未进
- `Command/Ctrl + Z`：撤销最近一次记录新增或删除
- `Command/Ctrl + Shift + Z`：重做刚撤销的记录操作

页面视频区域下方也提供可展开和关闭的“快捷键说明”。

## 数据与代码结构

- `src/domain/annotation-project.ts`：标定工程、投篮记录、关键帧、版本迁移与导出规则
- `src/domain/highlight-plan.ts`：高光范围、投篮统计、事件纳入、片段合并与修剪规则
- `src/domain/highlight-playback.ts`：连续预览的片段跳转决策
- `src/HighlightPanel.tsx`：高光预览的浏览器界面 Adapter
- `src/domain/video-geometry.ts`：帧步进和视频坐标换算
- `src/App.tsx`：本地工作台与浏览器视频 Adapter
- `tests/fixtures/legacy-annotation.json`：旧格式迁移样例
- `CONTEXT.md`：领域词汇
- `docs/adr/`：架构决策

## 累计 SY 高光统计字幕

将同一场比赛的原始 SY SRT 按时间顺序传入。首段作为累计基数，不生成新文件；之后每段都会在同一目录生成带 `_累计.srt` 后缀的文件。时间戳和“总得分”文本保持原样，只更新“命中 / 出手 命中率”。

```bash
npm run accumulate-sy-srt -- \
  '/path/to/第一段_sy高光_高光统计字幕.srt' \
  '/path/to/第二段_sy高光_高光统计字幕.srt' \
  '/path/to/第三段_sy高光_高光统计字幕.srt'
```
